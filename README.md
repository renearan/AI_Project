# Actividad Formativa: GitHub Copilot y Tendencias de IA

## Descripción de la Actividad

Este repositorio contiene el desarrollo de la actividad práctica enfocada en el uso de herramientas de asistencia y control de versiones con Git.

---

## Pasos Realizados

1. **Creación del Repositorio:**
   - Se creó un repositorio público llamado `AI_Project` en la plataforma de GitHub.

2. **Configuración Local (CMD):**
   - Se abrió la terminal de comandos (CMD) de Windows.
   - Se clonó el repositorio en el equipo y se configuraron las credenciales locales de Git para el proyecto.

3. **Desarrollo del Script en Python:**
   - Se creó el archivo `recommendation_system.py` utilizando las librerías estándar y `psutil` para monitorear el rendimiento del sistema operativo en tiempo real.

4. **Control de Versiones (Git Commit & Push):**
   - Se empaquetaron y subieron los cambios al repositorio remoto ejecutando los siguientes comandos en CMD:
     ```cmd
     git add .
     git commit -m "Add system performance monitoring script"
     git push origin main
     ```

5. **Se uso Copilot para completar e implementar el codigo**

- Se escribio una línea y dio el prompt adecuado para llegar al resultado final.
